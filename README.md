# AI-Powered Smart Attendance Management System

An intelligent attendance management system that uses Artificial Intelligence and Face Recognition to automate student attendance tracking, reduce manual work, and improve accuracy.

## 🚀 Project Overview

The AI-Powered Smart Attendance Management System automates the attendance process using facial recognition technology. It identifies students through their faces and helps teachers manage attendance efficiently.

The system provides separate interfaces for teachers and students, making attendance tracking easier and more organized.

## ✨ Key Features

- AI-Based Face Recognition
- Automated Attendance Tracking
- Teacher and Student Login
- Student Attendance Management
- Attendance Records
- Automatic Student Identification
- Interactive Streamlit Interface
- Session-Based User Management

## ⚙️ Installation

**1. Clone the repository**

```bash
git clone https://github.com/Mymudh/ai-powered-smart-attendance-system.git
```

**2. Navigate to the project directory**

```bash
cd ai-powered-smart-attendance-system
```

**3. Install dependencies**

```bash
pip install streamlit opencv-python numpy pandas
```

**4. Run the project**

Open the Jupyter Notebook in Google Colab or Jupyter Notebook and execute the cells.
